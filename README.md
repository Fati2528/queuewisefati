QueueWise — Queue Wait-Time Intelligence

About the Project

QueueWise is a beginner-friendly Java project that estimates the waiting time of a person standing in a queue.

Objective

The objective is to calculate the estimated waiting time based on the number of people ahead and the average service time per person.

Technologies Used

- Java
- Core Java

Features

- Store the number of people ahead in a queue.
- Calculate the estimated waiting time.
- Display the result.
