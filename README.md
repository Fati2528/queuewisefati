QueueWise — Queue Wait-Time Intelligence

About the Project

QueueWise is a beginner-friendly Java project that calculates and compares the estimated waiting time of two queues.

It helps identify which queue has a shorter waiting time.

Objective

The objective is to calculate the estimated waiting time based on the number of people ahead and the average service time per person.

Technologies Used

- Java
- Core Java

Features

- Store the number of people ahead in two queues.
- Calculate the estimated waiting time for both queues.
- Display the details of both queues side by side.
- Compare the waiting times of both queues.
- Identify the faster queue.

Java Concepts Used

- Variables and Data Types
- Arithmetic Operators
- Comparison Operators
- For Loop
- If-Else Statements
- Print and Println Statements

Waiting Time Calculation

Waiting Time = Number of People Ahead × Service Time per Person

Example

Queue 1

- People Ahead: 5
- Service Time: 3 minutes
- Waiting Time: 15 minutes

Queue 2

- People Ahead: 3
- Service Time: 4 minutes
- Waiting Time: 12 minutes

Result: Queue 2 is faster because it has a shorter estimated waiting time.

How to Run the Project

1. Install the Java JDK.
2. Save the program as "Main.java".
3. Open Command Prompt or a terminal in the folder containing the file.
4. Compile the program using "javac Main.java".
5. Run the program using "java Main".
